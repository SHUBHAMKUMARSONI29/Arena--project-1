# 🌐 Personal Portfolio Website

A simple and professional **Personal Portfolio Website** created using **HTML5**. This project showcases personal information, technical skills, projects, and contact details in a clean and organized structure.

## 📌 Project Overview

The purpose of this project is to create a personal portfolio website that introduces the developer and highlights their skills and projects.

The website contains multiple sections with internal navigation and a contact form with HTML validation.

## ✨ Features

* 👤 About Me section
* 🛠️ Technical Skills section
* 💼 Projects section
* 📩 Contact form
* 🔗 GitHub and LinkedIn links
* 🖼️ Profile image with proper `alt` text
* 🧭 Internal navigation links
* ✅ HTML5 form validation
* 📱 Responsive HTML structure
* 🧱 Semantic HTML elements

## 🛠️ Technologies Used

* **HTML5**

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Make sure `index.html` and `profile.jpg` are in the same folder.
4. Open `index.html` in a web browser.
5. Navigate through the different sections using the navigation menu.
